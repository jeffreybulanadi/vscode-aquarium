# Logo Brief for VSCode Aquarium Extension

## Project Overview
**VSCode Aquarium** is a VS Code extension that simulates a living aquarium with animated fish inside the editor. It's a productivity tool that brings calm, engaging visuals to coding sessions.

---

## Visual Requirements

### Core Concept
A **minimalist, modern aquarium with animated fish** that communicates:
- **Relaxation & focus** (calming presence while coding)
- **Life & movement** (animated, dynamic)
- **Technology** (VS Code integration, tech-friendly)
- **Clarity & simplicity** (clean lines, professional)

### Key Elements to Include
1. **Aquarium vessel/glass** — subtle outline or gradient, not overly literal
2. **Fish** — 1-3 stylized fish in profile (swimming right), colorful (blues, greens, oranges)
3. **Water** — implied through color gradients or subtle waves
4. **Plants/life** — optional subtle aquatic plant or bubble
5. **VS Code color theme harmony** — works on both light & dark themes

### Style Direction
- **Modern minimalist** with slight artistic flair
- **Geometric or slightly stylized** (not photorealistic)
- **Retro-modern** vibe (inspired by vscode-pets but more polished)
- **Depth** — use layers/gradients to create dimension
- **Active feeling** — suggest motion (curved lines, dynamic composition)

---

## Technical Specs

### Deliverables Needed
1. **Square logo** (essential for marketplace):
   - 128×128 px (minimum)
   - 256×256 px (preferred, higher quality)
   - 512×512 px (nice to have)

2. **Format**: PNG with transparency preferred (can convert SVG → PNG)

3. **Color requirements**:
   - Must be identifiable on **both light & dark** VS Code themes
   - Primary colors: aqua/cyan blues, water greens, warm fish tones (coral, gold)
   - Ensure 5:1+ contrast ratio for accessibility

4. **Safe area**: Keep main elements in center 80×80 px (128 px canvas) to avoid clipping on marketplace/marketplace thumbnails

### Optional Deliverables
- **SVG source file** (for future scaling)
- **Color variants**: One for dark theme, one for light theme (if needed)
- **Animated GIF** (16-frame loop, 256×256 px, <500 KB) for marketplace showcase

---

## Examples/Inspiration
- **Aesthetic**: Combine the friendly approachability of vscode-pets with professional minimalism
- **Fish style**: Stylized but recognizable (think: icon-level detail, not cartoon)
- **Palette**: Primary aqua/cyan, secondary coral/gold, accent greens
- **Mood**: Serene, engaging, inviting
